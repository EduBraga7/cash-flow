## 📖 Sobre o Projeto

O **CashFlow** foi concebido para centralizar e profissionalizar todas as operações de um negócio de desenvolvimento web e serviços digitais. 

Mais do que uma planilha de entradas financeiras, o sistema integra um **CRM completo de clientes**, um **Quadro Kanban de demandas técnicas e projetos pessoais**, uma **Biblioteca de Prompts & Componentes de UI** e um poderoso **Consultor Executivo com Inteligência Artificial (Google Gemini)** que analisa dados reais em tempo real para acelerar o crescimento do seu faturamento e receita recorrente (MRR).

---

## ✨ Funcionalidades Principais

* 💰 **Previsibilidade Financeira:** Controle de contratos recorrentes (MRR), lançamentos avulsos, status de recebimento e projeções de ARR (Annual Recurring Revenue).
* 🏢 **Fichas de Clientes & Cases:** Cadastro detalhado com links dos sites em produção, repositórios no GitHub, notas de contrato e stack tecnológica.
* 📋 **Quadro Kanban com Duplo Escopo:** Organização ágil de sprints separando **Demandas de Clientes** de **Projetos Pessoais & Estudos** (ex: PromptVault, CashFlow), com prioridades, prazos e estimativa de horas.
* 🧩 **Central de Prompts & Componentes:** Acervo de códigos React/Tailwind e prompts otimizados de IA categorizados com a ferramenta de destino (ChatGPT, Google Labs, Midjourney).
* 🧠 **Cérebro Estratégico com IA (Gemini):** Diagnóstico contínuo do negócio, alertas de risco de concentração de receita, propostas de upsell e scripts de WhatsApp em 1 clique.
* 🌙 **Interface Moderna & Dark Mode:** UI desenvolvida em Tailwind CSS com componentes Radix UI (shadcn/ui), responsiva e de alta performance.
* ☁️ **Sincronização em Tempo Real:** Banco de dados NoSQL Firebase Firestore com listeners eficientes e autenticação completa.

## 🏛️ Módulos do Sistema

### 1. 📊 Visão Geral & Painel Financeiro
* **Métricas Principais:** Faturamento Total, Total Já Recebido, Total a Receber e **MRR Atual**.
* **Tabela de Lançamentos:** Filtros por período, tipo de contrato, status de pagamento e busca dinâmica.
* **Cadastro Rápido:** Modal intuitivo para novos pagamentos ou contratos recorrentes com parcelamento inteligente.

### 2. 👥 Clientes & Projetos de Portfólio
* Gestão dos clientes ativos e cases de sucesso.
* Acesso direto com 1 clique para o site no ar e repositório do código-fonte.
* Tags de tecnologia utilizadas no projeto (Next.js, Tailwind, React, Firebase, etc.).

### 3. 📌 Quadro Kanban de Tarefas & Sprints
* **Colunas de Status:** `A Fazer`, `Em Andamento` e `Concluído`.
* **Separação de Escopo:**
  * 💼 **Demandas de Clientes:** Manutenções mensais, ajustes de layout, novas páginas e correções de bugs.
  * 🚀 **Projetos Pessoais & Estudos:** Tarefas internas para evolução dos seus próprios SaaS e produtos.
* **Filtros Ágeis:** Filtre instantaneamente por escopo, prioridade (Urgente, Alta, Média, Baixa) ou cliente específico.

### 4. 🧩 Biblioteca & Prompts (PromptVault)
* Prompts de Inteligência Artificial para criação de campanhas, copies e landing pages.
* Identificação clara de onde utilizar cada prompt (*ChatGPT*, *Google Labs*, *Midjourney*, etc.).
* Blocos de código e componentes reutilizáveis com botão de cópia rápida.

## 🧠 Inteligência Artificial Estratégica (Google Gemini)

O módulo de IA atua como um **sócio e consultor de negócios** conectado diretamente aos seus dados reais:

```
                  ┌───────────────────────────────┐
                  │   Dados em Tempo Real         │
                  │   • MRR & Faturamento         │
                  │   • Clientes & Cases          │
                  │   • Fila do Kanban            │
                  └──────────────┬────────────────┘
                                 │
                                 ▼
                  ┌───────────────────────────────┐
                  │      Google Gemini API        │
                  │     (Multi-Model Engine)      │
                  └──────────────┬────────────────┘
                                 │
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│   Radar Executivo│   │Lentes Estratégicas│   │ Arsenal de Ações │
│• Alerta de Risco │   │• Modo CFO        │   │• Prospecção Fria │
│• Oportunidades   │   │• Modo Comercial  │   │• Upsell WhatsApp │
│• Eficiência Fila │   │• Modo Tech Lead  │   │• Simulador "E se"│
└──────────────────┘   └──────────────────┘   └──────────────────┘
```

* 🚨 **Radar Executivo Automático:** Detecta pontos de atenção como concentração excessiva de receita em um único cliente ou cases livres sem contrato de manutenção mensal.
* 🎭 **Lentes de Consultoria:** Alterne entre **Modo CFO** (foco financeiro e metas), **Diretor Comercial** (scripts de vendas), **Tech Lead** (produtividade e código) ou **Mentor 360°**.
* 💬 **Chat Humanizado & Formatado:** Respostas diretas e sem enrolação, formatadas com tipografia limpa e botão de cópia.

## 🚀 Como Rodar o Projeto

### Pré-requisitos
* [Node.js](https://nodejs.org/) (versão 18 ou superior)
* `npm`, `yarn` ou `pnpm`
* Conta no [Firebase Console](https://console.firebase.google.com/)
* Chave de API no [Google AI Studio](https://aistudio.google.com/)

### 1. Clonar o repositório
```bash
git clone https://github.com/EduBraga7/cash-flow.git
cd cash-flow
```

### 2. Instalar dependências
```bash
npm install
```

### 3. Configurar variáveis de ambiente
Crie um arquivo `.env.local` na raiz do projeto com as seguintes chaves:

```env
NEXT_PUBLIC_FIREBASE_API_KEY=seu_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=seu_projeto.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=seu_projeto_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=seu_projeto.firebasestorage.app
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=seu_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=seu_app_id

GEMINI_API_KEY=sua_chave_gemini
NEXT_PUBLIC_GEMINI_API_KEY=sua_chave_gemini
```

### 4. Executar em modo de desenvolvimento
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## 🌐 Deploy na Vercel

1. Faça o push do código para o seu repositório no **GitHub**.
2. Acesse a [Vercel](https://vercel.com/) e clique em **Add New Project**.
3. Importe o repositório `cash-flow`.
4. Em **Environment Variables**, adicione todas as variáveis contidas no `.env.local`.
5. Clique em **Deploy**. O projeto será construído e disponibilizado com SSL automático e CDN global.
